Plano de implementação
Fase 1 Setup
Ambiente e estrutura do projeto
Montar o alicerce técnico com Docker, Python isolado, GPU configurada e estrutura de pastas. Erros aqui custam caro depois — validar CUDA funcionando antes de qualquer código de negócio.
Criar docker-compose.yml com serviço Python (GPU passthrough via nvidia-docker) e serviço frontend docker compose
Instalar NVIDIA Container Toolkit para expor a GTX 1650 ao container nvidia-docker
Instalar PyTorch com CUDA 11.8 e validar torch.cuda.is_available() pytorch.org
Inicializar projeto FastAPI com estrutura backend/, frontend/, storage/ fastapi
Docker nvidia-docker Python 3.10 FastAPI CUDA 11.8
Risco
Driver NVIDIA desatualizado faz torch.cuda.is_available() retornar False silenciosamente. Testar isoladamente antes de continuar.
Fase 2 Core
Pipeline de separação e download
O coração do projeto. Demucs separa os stems, yt-dlp faz o download, Spotipy lê as playlists. Processamento assíncrono para não bloquear a API enquanto a GPU trabalha.
Integrar Demucs (htdemucs) com wrapper Python que aceita caminho de arquivo e retorna paths dos stems gerados demucs
Implementar downloader com yt-dlp que recebe query "artista + título" e retorna WAV em storage/raw/ yt-dlp
Usar Spotipy para ler playlists via API oficial do Spotify e extrair metadados (nome, artista, duração) spotipy
Criar endpoint POST /process que enfileira job de separação com BackgroundTasks do FastAPI e retorna job_id background tasks
Implementar WebSocket /ws/{job_id} para streaming de progresso em tempo real ao frontend websocket
Demucs htdemucs yt-dlp Spotipy asyncio WebSocket
Risco
Músicas longas (+6min) podem estourar os 4GB de VRAM. Usar --segment 7 no Demucs como padrão defensivo desde o início.
Fase 3 Player
Player multi-stem no frontend
Interface React com Web Audio API. Todos os stems carregam em um único AudioContext para garantir sincronização perfeita. Controle de volume e mute por canal, waveform visual.
Implementar AudioContext com um GainNode por stem — todos iniciados no mesmo instante via AudioBufferSourceNode.start(ctx.currentTime) web audio api
Integrar WaveSurfer.js para renderizar waveform visual e seekbar interativa de cada stem wavesurfer.js
Criar componente StemChannel com controle de volume (slider), mute toggle e indicador de nível (VU meter simples)
Mostrar barra de progresso do processamento via WebSocket — estados: downloading → separating → ready SSE / WS
React Web Audio API WaveSurfer.js Vite
Atenção
Browsers bloqueiam AudioContext sem interação do usuário. Criar o contexto apenas após primeiro clique — nunca no useEffect de montagem.
Próximos passos (pós-MVP)
v2 Análise
Análise musical e transcrição
Com o pipeline de separação funcionando, adicionar camadas de análise sobre os stems isolados. BPM no stem de drums é muito mais preciso que no mix completo.
BPM via librosa.beat.beat_track() no stem de drums — expor resultado no player com tap tempo visual librosa beat
Detecção de notas via Basic Pitch (Spotify, open source) — gerar MIDI do stem de bass e vocals basic-pitch
Transcrição de bateria: onset detection + classificação por centroide espectral (kick / snare / hihat) onset detect
Exportar transcrição como MIDI com pretty_midi — visualizar no frontend como piano roll ou partitura simplificada pretty-midi
